# 纸上文明

画画发展文明的游戏《纸上文明》的样机。你是神，用三支笔管一个部落：墨笔写符下号令，铅笔画路、探路，朱笔划界；房子照图纸画，画得好，房子就好。

- 构想：[docs/纸上文明_构想.md](docs/纸上文明_构想.md)
- M0 识别样机：写符认得准、三支笔不打架、图纸量得出数值。见 [docs/M0_报告.md](docs/M0_报告.md)
- M1 部落白盒：十个有名字的族人自己过日子，机器人当神能活过两年。见 [docs/M1_报告.md](docs/M1_报告.md)

## 打开

```bash
node serve.mjs
```

- 部落（M1）：http://localhost:5320/
  - 白纸地图上，族人自己吃喝、干活、过冬。地图只画出营地周围，别处要派人去探。
  - 墨笔在目标上写符就是号令，墨从族人的爱戴和敬畏里来。
  - 铅笔探路、修路、迁徙；朱笔封锁、✕ 禁、○ 护。
  - 「图纸」里照淡影画火塘、窝棚、晾肉架、篱笆。
  - 顶栏「托管」让机器人替你当神；`?seed=数字` 固定地图。
- 三支笔沙盘（M0）：http://localhost:5320/sandbox.html
- 符号实验室：http://localhost:5320/lab.html
  - 试写：看三路识别各自的把握。
  - 采样：给真人复核用。
  - 示范三遍：让它认得你的笔迹。
  - 评测、导出。

不用安装依赖，只要 Node 22。浏览器端是原生 ES 模块和 Canvas。

## 命令

| 命令 | 做什么 |
|---|---|
| `npm test` | 34 项测试：反向传播、符圈、朱笔、图纸、部落模拟、机器人（约 3.5 秒） |
| `npm run sim` | 过关测试：20 个种子，各跑两年「不管」和「机器人当神」，写 `docs/sim.md`（约 20 秒） |
| `npm run sim -- --seeds 1-5 --days 28 --no-write` | 只跑几个种子、几天，不改报告；`--no-rec` 让机器人跳过识别器 |
| `npm run check` | 识别体检，写 `docs/glyphcheck.md`（约 3 分钟） |
| `npm run check -- --human 样本.json` | 加评真人样本（实验室「数据」页导出） |
| `npm run train` | 重训模型，写 `model/glyph.json`（14 线程约 6 分钟） |
| `npm run tune -- --write` | 重调拒识、生效门槛，写回模型 |
| `npm run sheet` | 十个符的合成样本缩略图 |

```
src/sandbox/  三支笔沙盘（M0）、图纸面板
src/lab/      符号实验室
src/ui/       画笔、宣纸、指针、本机存取、样式
tools/        训练、调门槛、识别体检、缩略图、过关测试
model/        glyph.json：int8 权重 + 出厂原型 + 门槛（69 KB）
test/         node --test
参考图/       构想用的 AI 参考图
```
