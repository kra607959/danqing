# 《纸上文明》M1 部落白盒：报告

2026-11-19

## 结论

**过关。** 构想里 M1 的过关线是「机器人能活过两年」。这次把线定得更严：

- 机器人当神，20 个种子里至少 18 个活过两年（56 天）且剩 ≥ 8 人；
- 平均人数比没有神时多 3 人以上。

| | 机器人当神 | 没有神 |
|---|---|---|
| 活过两年且剩 ≥ 8 人 | **20 / 20** | 6 / 20 |
| 两年后平均人数 | **11.8** | 4.3 |
| 灭族 | 0 | 7 |
| 平均死亡 / 出生 | 0.1 / 1.9 | 6.3 / 0.7 |

逐个种子的结果见 [sim.md](sim.md)，用 `npm run sim` 重跑，20 个种子约 20 秒。

机器人写符走的是真识别器：合成笔迹，加手抖。两年里写了 1745 次，99.8% 直接生效，0.2% 进了「请选」。图纸也是照淡影一步步画的，553 步里有 32 步没量出来，重画了。

还没有真人试玩数据。按约定，真人数据只作复核点，不卡下一步。

## 怎么打开

```bash
cd D:/Game/danqing
node serve.mjs
```

- 部落（M1）：http://localhost:5320/
- 三支笔沙盘（M0）：http://localhost:5320/sandbox.html
- 符号实验室：http://localhost:5320/lab.html

在网址后面加 `?seed=数字` 可以固定地图。1 倍速下一天约 1 分钟，两年约 56 分钟；8 倍速约 7 分钟。顶栏的「托管」让机器人替你当神，它写的每一个符都会画在地图上。

| 操作 | 怎么做 |
|---|---|
| 看 | 拖动挪地图；滚轮或两指缩放；右键、中键拖也能挪。点一个族人，看他的小传 |
| 墨笔 <kbd>2</kbd> | 在目标上写符，停笔约半秒就认。写在屏幕顶上那一条「天」上：雨（降雨）、火（雷火，再点要劈的地方） |
| 铅笔 <kbd>1</kbd> | 画一条线，再选探路、修路或迁徙。线伸进白纸时，默认选探路 |
| 朱笔 <kbd>3</kbd> | 长线是封锁线；首尾相接是禁区；小 ✕ 是禁伐、禁猎；小 ○ 是护；一刀划破自己的线是启封 |
| 图纸 <kbd>4</kbd> | 火塘、窝棚、晾肉架、篱笆，照淡影一步步画。火塘、窝棚、晾肉架画完点地图落地；篱笆用铅笔画走向 |
| 其他 | <kbd>空格</kbd> 暂停 / 继续，<kbd>Q</kbd> 看，<kbd>H</kbd> 回营地，<kbd>Esc</kbd> 取消，<kbd>Enter</kbd> 立刻收笔 |

## 二、两年里发生了什么

没有神的部落熬得过春夏秋，吃的多到放坏，然后死在冬天：

- 鲜肉三天、浆果四天就坏，入冬一场霜浆果全落；
- 鹿跑远、鱼少，人又饿得快；
- 挨饿时老人、小孩先倒。

二十个种子里有七个灭族，最早的在第 31 天。

机器人赢在神给的东西：

- 晾肉架加秋天围猎：干肉能放 40 天，冬天有吃的。二十个种子合计晾了 669 份，没有神的是 0 份。
- 窝棚：人肯生养，夜里不冻。
- 火塘：省柴，更暖。
- 篱笆：挡冬天的狼。
- 驱兽和雷火：虎、狼扑人时驱兽；虎在营地边转就劈。
- 探路：白纸画出来，才找得到新的林子和鹿群。

这正是构想要的手感：神不替族人干活，只在要紧处点拨。不点拨，部落熬不过冬天。

## 三、浏览器里验过的

全按真实时钟跑，不是只在 Node 里步进：

- 开局、昼夜、白纸迷雾、营火光圈、族人名字和活计都能显示；控制台没有报错。
- 模拟手写「树」写在营地上：认出来，三人去采集，扣 1 墨，弹出 3 秒撤回。在天上写「雨」：降雨。写「火」：进入瞄准，点地图劈下雷火。
- 铅笔：画一条伸进白纸的线，弹出探路、修路、迁徙，默认选探路，派出两人。
- 朱笔：长线封锁（2 墨，承受 83），✕ 禁伐林子。
- 图纸：
  - 火塘：三步都量出来（火力 24°、暖到 120 步、省柴 28%、有棚），点地图落成工地，族人自己去备料、盖好。
  - 篱笆：画完再用铅笔画走向，修了 10 段。
- 托管 8 倍速：五秒里没有一帧超过 50 毫秒。再在浏览器里快进到第二年冬末，用 4 倍速跨过第 56 天，弹出「两年了，部落还在」。
- 灭族：弹出结算，可以重开或换一张纸。
- 平板（768 宽）：顶栏两行，提示在笔的上方。手机（375 宽）：编年默认收起，只露最新一条。
- 沙盘和实验室照常打开，页面之间互相有链接。

## 四、这次查出来、已经修掉的问题

- **没有神时，结果随机得厉害。** 同一套规则，换无关的改动后，不管的平均人数从 4 跳到 9.5。修法是把冬天做得一定难过：入冬下霜、浆果四天就坏、冬天饿得快 1.3 倍、老人小孩饿得更伤。种子也从 10 个加到 20 个。
- **半个圈也被当成火塘的石圈。** 原来按外接框中心看角度覆盖，U 形能骗过去。改成看笔画首尾的缺口有多大，同时要求绕够四分之三圈。
- **机器人一直盖窝棚。** 它看的「住处」是每小时才算一次的计划，工地还没算进去，就会重复下令。改成直接数已建好的和正在盖的。
- **篱笆一段一段的工地，配置里没有登记**，机器人一下令就崩。已补上。
- **界面上的几处：**
  - 落地成功、劈完雷火的提示，被「切回看」的说明盖掉了。
  - `hidden` 被 `display:flex` 盖住，族人小传关不掉。
  - 白雪画在浅色宣纸上看不见，改成淡墨点加白边。
  - 「托管中」的按钮字太长，把顶栏挤成两行。
  - 空格暂停后再按，总是回到 1 倍速；现在回到暂停前的速度。

## 五、和构想的出入

- **神迹做了三个，不是两个**：降雨、圣光，加雷火。敬畏要有个来处，而第一代别的号令都只涨爱戴。
- **「信仰」没有单列成第三个数**：它就是虔诚，决定墨回得多快。界面上只显示爱戴、敬畏和墨。M2 有了叛乱、密谋，再看要不要单列。
- **开场还是十个人**，没有做「画第一个人、点睛」。这是演出，放到做满第一代时。
- **地图是生成的**，不是玩家画的。玩家改的是路、篱笆、房子、禁区，和被雷火、烧荒烧掉的林子。
- **一天约一分钟**，两年 56 分钟。构想要第一代首玩 3–4 小时，那是 M2 加了科技、对手、天才和时代工程之后的事。

## 六、还没定的、要留意的

- **墨在机器人手里总是满的。** 两年平均只花了约 150 墨，每天 2–3 墨，回得却有每天 12 墨左右。真人可能花得多，也可能乱花。先看试玩；如果大家都不缺墨，就压回墨的速度，或者给大神迹涨价。
- **机器人打猎打得太狠**，鹿群会被打光，全靠开春从山那边再来。M2 加「禁猎」的长期好处（鹿群回涨），让朱笔 ✕ 有意义。
- **不管的结果仍有运气成分**：二十个种子里，有六个没有神也能剩八人以上。这也合理：好年景本来就有。
- **真人复核**：
  1. 找人从头玩一局，不讲规则，只看手册和提示。
  2. 记下几件事：多久想到要晾肉、过冬死了几个、哪个符老是写不对、墨够不够用。
  3. 打开实验室「数据」页导出笔迹，用 `node tools/glyphcheck.mjs --human 文件.json` 评。

## 七、下一步

**M2 部落做满。** 内容是第一代全部科技、威胁、对手、天才、时代工程和考验。过关线是首玩 3–4 小时，机器人模拟里粮、人口、墨的曲线合理。

先做的几件：

- 墨的经济：按试玩数据或更真实的机器人重调；神迹分级。
- 叛乱与密谋：敬畏远高于爱戴时，有人反你。
- 天才与发明：族人自己想出东西，记进编年。
- 第一代的时代工程，和通往下一代的考验。
- 开场演出：画第一个人、点睛。
