# 部落白盒：机器人能不能活过两年

由 `node tools/sim.mjs` 生成（2026-11-19）。每个种子从同一张地图、同样 10 个族人开局，跑 56 天（2 年）。

- **不管**：没有神。族人自己找吃的、砍柴、看火、躲野兽，没有图纸也没有号令。
- **机器人**：按一套规则当神（`src/sim/bot.js`）。写符走真的识别器（合成笔迹加手抖，拿不准就从候选里挑，认错了撤回重写）；图纸照淡影加手抖一步步画；墨、木头、石头、人手和玩家一样受限。

## 结论：过关

| | 机器人 | 不管 |
|---|---|---|
| 活过两年且剩 ≥ 8 人 | **20 / 20** | 6 / 20 |
| 两年后平均人数 | **11.8** | 4.3 |
| 灭族 | 0 | 7 |
| 平均死亡 | 0.1 | 6.3 |
| 平均出生 | 1.9 | 0.7 |
| 晾成干肉（份） | 669 | 0 |
| 放坏的吃的（份） | 0 | 267 |

过关线：机器人 ≥ 18/20 个种子剩 ≥ 8 人，且平均人数比不管的多 3 人以上。

## 机器人做了什么（20 个种子合计）

- 图纸：火塘 20、窝棚 65、晾肉架 46、篱笆 20；画了 553 步，32 步没量出来要重画。
- 号令：近处采集 405、围猎 305、砍伐 278、采集（林） 205、叉鱼 177、狩猎 137、降雨 78、驱兽 74、传火 32、采石 27、雷火 13、圣光 13。
- 探路（铅笔）：260 次。
- 写符 1745 次：直接生效 99.8%，拿不准挑了 0.2%，不认 0.1%，「这里用不上」0.0%，认错了撤回 0.0%；三回都没写成放弃 0 次。

## 读法

- 不管的部落熬得过春夏秋（吃的多到放坏），死在冬天：鲜肉三天、鱼两天、浆果四天就坏；入冬一场霜浆果全落，鹿跑远、鱼少，人又饿得快。挨饿时老人小孩先倒。
- 机器人赢在神给的东西：晾肉架（干肉能放 40 天）加秋天围猎，冬天有吃的；窝棚让人肯生养、夜里不冻；火塘省柴更暖；篱笆挡冬狼；虎、狼扑人时驱兽，虎在营地边转就劈。
- 这套规则只是「会玩的人」的下限，不代表平衡定了：墨在机器人手里常常是满的，真人会花得更多，等试玩数据再调。
