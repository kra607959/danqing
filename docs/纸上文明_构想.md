# 《纸上文明》构想（第二版）

## 一、一句话

**你是一位只能用笔说话的神。** 世界是一张纸，族人是纸上的火柴人。你写下的符号是神谕和号令；画下的线是路、田和城墙；画下的图纸，由工匠照着一笔一笔造出来。

从石器部落到火箭升空，一共八个时代，每一代都是一整局游戏。族人记得你画过的每一笔，也记得你待他们是慈悲还是可怕。

## 三、核心

1. **笔是唯一的神力。** 你不能直接指挥哪一个人，只能写符、画线、画图纸。每一笔都花墨，墨从信仰里来。
2. **三支笔，各管一件事。** 铅笔画规划和图纸，墨笔写神符和号令，朱笔（参考图里的红笔）划界、下禁令。手上拿的是哪支笔，机器就只做那一种判断（见第四节）。
3. **族人是活的。** 每个人都有名字、年纪、亲人、手艺，会病，会老。技艺长在人身上，不传就会失传。天才很少：抢得到，也会被抢走。
4. **时代很长，世界一直在。** 一代就是一整局：开局、中段危机、时代工程、时代考验。换代不清空：旧时代的房子还在，熟练的活变成自动，你管的东西往上升一层。

## 四、画画会不会认错

### 1. 三种画，只有一种要「认」

| 笔 | 画什么 | 机器做什么 | 会不会认错 |
|---|---|---|---|
| 铅笔 · 规划 | 路、田界、渠、城墙、行军路线、铁轨、电线、跑道 | 只取几何：位置、走向、长短、闭没闭合 | 不会 |
| 铅笔 · 图纸 | 先在手册里选好「机库」或「桥」，再照提示一部分一部分画 | 目标已知，只量尺寸、比例、部件齐不齐 | 不会；画得好坏决定数值 |
| 墨笔 · 神符 | 日、月、雨、火、水、山、树、剑、旗、光……（动词看画在什么上面） | 在三到六个候选里分类 | 唯一要认的，见下 |
| 朱笔 · 禁令 | 封锁线、禁区、隔离圈；少数红符（✕ 禁止，○ 守护） | 线只取几何；红符只有两三个，形状差得远 | 基本不会 |

「画画认不准」的风险，因此只剩墨笔写的那十来个符号。

图纸的画法照参考图：画发射台时，先画直立的箭塔和高塔，最后在底部画一条横向平台。每一步提示画哪一部分，量的是这部分画得多高、多直、接没接上。数值跟着画走：塔画得高，承重和射程就大；跑道画得长，就能起降更重的飞机；城墙留了缺口，敌人就从缺口钻进来。上下都有限：画歪了不会废掉，画得好有奖励。

### 2. 墨笔符号怎么保准

1. **一个符一个圈。** 墨笔落下，周围浮出一个淡淡的符圈，圈里的笔画算同一个符。停笔约 0.45 秒就生效（落笔慢的人自动放宽，最多 0.9 秒），点一下圈外也行；在圈外起笔，就是下一个符。这样既不会把两个符连成一个，也不会把半个符当成一整个。
   - 圈要按已写的笔画放大一倍，先写树干、马上写树冠才不会被切开。M0 实测：圈太紧时，快写的大符有 23% 被切成两半；放大后约 1%。
2. **符是名词，画在什么上面决定动词和候选。**
   - 符都是象形的名词：日、月、雨、火、水、山、树、剑、旗、光。
   - 同一个「剑」，画在树林上是砍伐，画在兽上是狩猎，画在石堆上是采石，画在族人身上是操练。
   - 画在天上只比雨、日、月、火（降雨、放晴、入夜、雷火）；画在树林上只比剑、树、火、旗。
   - 再和「已解锁」取交集，每次真正参与比较的只有 3–6 个。第一代 10 个符就能下 29 种号令。全游戏的符可以有一两百个，每次比的始终只有这几个。
3. **先把符号设计得互不相像。** 同场出现的任意两个符，至少要在两项粗特征上不同：笔数、圈数、主方向、有没有交叉、是曲是直、是高是扁。参考图里的木剑、铁剑、太刀、唐刀不做成四个符：只写一个「剑」，造出哪种剑由科技和材料决定。
4. **三路合判。**
   - 一是小卷积网。M0 用 32×32 灰度、三层卷积（8/16/32）、64 维特征，10 个符加「乱画」共 11 类。39k 个参数，int8 存储 69 KB。比参考图的 48×48 小一半也够用。
   - 二是点云模板（墨灵 `glyph.js` 的思路）。
   - 三是拿 CNN 的特征和每个符的原型比相似度。
   - 三路一致、而且都有把握，才直接生效；有分歧就请选；CNN 说是乱画，或者和所有原型都不像，就是神意不明。
5. **认得你的笔迹。** CNN 把一个符变成一串特征，再和每个符的「原型」比。原型起初是出厂的通用写法：每解锁一个新符，有一段「示范给族人看」，你写三遍，原型就加进你的写法。之后每次生效的符也记进去，每个符保留最近 30 个。玩家机器上不用训练，写完就能用，而且越写越准。
6. **认错了，代价很小。**
   - 认出来时，符圈上先显出符名的虚影。
   - 拿不准时，弹出前两三个候选让你点。
   - 完全认不出，参谋说「神意不明」，不扣墨。
   - 生效后 3 秒内可以撤回，墨退回。
   - 血祭、人柱、迁徙、宣战这类收不回来的，一律要再点一下确认。
7. **永远有退路。** 每个符都能从手册里点出来，再点目标，只是慢一点、贵一点。设置里可以关掉写符。

族人能同时认得的神符有上限，要靠司祭、文字、经书一代代提高。这既是玩法：文明越高，你能下的神谕越多。也让开局候选少，识别稳。

### 3. 指标与工具

| 指标 | 目标 |
|---|---|
| 当前候选里第一猜就对 | ≥ 97% |
| 乱画被拒 | ≥ 95% |
| 认错了还被执行 | 约等于 0（虚影、撤回、确认三道关） |
| 识别耗时 | ≤ 10 ms |

- **数据**：
  - 从标准写法合成样本：每个符几种常见写法，再加平移、缩放、旋转、错切、笔画抖动、断笔、多一笔、反向、粗细变化。M0 训练时每一步现合成，共用了 106 万条。
  - 乱画也合成：26 类进训练（乱涂、螺旋、方框、火柴人、随手拼的几笔……），另留 10 类从不进训练（汉字笔画、字母、鱼、船、伞、鸟……），专门测「没见过的乱画」。
  - Quick, Draw!（谷歌公开，CC BY 4.0）M0 没有用：合成数据已经够过机器测，以后需要再下。
  - 再找朋友在符号实验室里写，每人每个符写十来遍，作复核点。
- **符号实验室**（参考图一）做成开发工具：试写、采样、示范三遍、评测、导出数据集。训练也用 JavaScript（`tools/train.mjs`，多线程，约 6 分钟），不引 Python，导出权重给游戏用。
- **混淆检查**：每加一批新符，跑一遍两两混淆表。同场出现的任意两个符，混淆超过 1% 就改符号的设计，而不是去调模型。
- **玩家端**：参考图七的样本管理留给玩家，改名「族人学认你的字」，可以看、补写、删掉写坏的样本。训练轮数、批大小这些参数只放在开发工具里。

### 4. 要不要干脆不画

| 方案 | 识别风险 | 结论 |
|---|---|---|
| 全自由画，机器猜你画的是什么 | 高 | 不推荐 |
| 三支笔（上面这套） | 只有墨笔符号一处，可控 | **推荐** |
| 符号改成盖印或点选，只保留画线和画图纸 | 没有 | 墨笔识别达不到指标时的退路 |
| 完全不画 | 没有 | 就成了普通的经营游戏，不推荐 |

还有一个可选做法：大神迹用「描符」。屏幕上浮出符的淡影，你一笔描完，描得越准越快，神迹越强。描符不需要识别，还多一点仪式感，适合降下圣光、不季之穗这一级的神迹。

## 五、三层循环

| 层 | 时长 | 你做什么 |
|---|---|---|
| 一笔 | 几秒 | 写一个符、画一条路、补一块图纸 |
| 一季（7 天） | 十来分钟 | 管吃住和士气；应付天灾、兽群、疫病；定研究；修建筑 |
| 一代 | 3–5 小时 | 追时代工程，对付对手，找天才，过考验，决定何时升代 |

- 1 倍速下一天约 1 分钟，一年 28 天。可以暂停、快进。
- 地图一开始是白纸，探过的地方才画出来。每一代地图往外长一截：河谷 → 平原 → 群山 → 海岸 → 海外 → 天空。
- **每一代你管的东西往上升一层**：一个个人 → 一个村 → 一座城 → 几座城 → 一个国 → 工厂和铁路 → 电网和前线 → 整张纸。
- 熟练的活变成常令，比如「砍伐」变成按定额自动砍，把你的注意力留给新的那一层。参考图里的「营地分工」就是常令表：每种活派几个人。

## 六、神格：爱戴、敬畏、信仰、墨

- **信仰**：信你的人数和虔诚程度，决定墨回得多快。
- **爱戴**：来自施恩，如降雨、圣光、丰收、治病。爱戴高，族人干活心甘情愿，很少叛乱。
- **敬畏**：来自降罚，如雷火、灾异、血祭。敬畏高，号令执行得快，但士气低、族人怕你；敬畏远高于爱戴时，会有人密谋反你。
- **墨**：你唯一的花销。墨池决定墨的上限。

神格树用参考图里的名字，分三支：

| 支 | 神迹 | 作用（初值） |
|---|---|---|
| 光 | 降下圣光 | 范围内士气 +20%、劳作 +15%、恐惧 −50%，持续 1 天，约 5 墨 |
| 光 | 不季之穗 | 一块田反季成熟 |
| 光 | 传梦使 | 托梦给一个人：教他一项技艺，或预告一场灾 |
| 光 | 传习者 | 师傅带徒弟快一倍 |
| 光 | 圣油墨池 | 墨的上限和回复速度提高 |
| 渊 | 雷火 | 劈开巨石、烧掉蝗虫，也能惩罚人 |
| 渊 | 血圈活祭 | 献祭换一大笔墨；敬畏大涨，爱戴大跌 |
| 渊 | 人柱 | 献一个人，让一项大工程更坚固、提前完工 |
| 渊 | 渊底墨池 | 墨回得更快，但墨色发黑，用它画的东西会出怪事 |
| 渊 | 纸下之眼 | 看穿全图：伏兵、异端、密谋 |
| 渊 | 造户成军 | 按户强征成军 |
| 制 | 立教、司祭 | 有了教和司祭，族人能认得的神符上限提高 |
| 制 | 铸钟之誓 | 钟声所及之处，信仰稳定 |
| 制 | 兴建工坊 | 工坊里的图纸造得更快 |
| 制 | 立法 | 把一道神谕写成律令，长期生效，不必每次花墨 |

纸面也跟着变：爱戴高的地方开出水彩小花，敬畏高的地方溅着朱红墨点。

后期有一个刻意的转折：工业化以后，人越来越不需要神，信仰会自然下滑。你得换一种方式被需要，比如托梦给发明家、在报纸上显灵、立法而不是亲自下令。神从发号施令，变成在纸下面推一把。

## 七、族人与知识

- **人**：每个人都有名字、年纪、亲人、手艺、性情、健康，以及对你是爱还是怕。日志像一部编年史，记下谁出生了、谁病了、谁发明了什么、你哪一年降过什么神迹。参考图里「阿禾病了。小杏病了……」就是这种。
- **技艺长在人身上**：每项技艺由具体的人掌握，师傅要花几天带徒弟；会的人都死了，这项技艺就失传。壁画（第一代）、书简（第三代）、印刷（第五代）、电报和图书馆（后期）一代代让知识更难丢。这也是每次换代真正改变的东西。
- **研究要有人做**：当前研究由最合适的人花几天去试（参考图里「打制石器 2/3 天」），会相关手艺的人越多，试得越快。
- **天才**：少见的人，能把科技往前推一大截，或者主持时代工程。学堂和开科会多出天才；也能从别族抢来（参考图：「带回他们的天才」）。你自己的天才也可能被抢走、被收买。
- **开场**：游戏从你画第一个人开始。照着淡影画一个火柴人，点一下他的头（点睛），他就活了。之后的人都是生出来的，只有「造人」这个昂贵的神迹能再画一个。

## 八、战争

- 铅笔画行军路线，队伍沿路走到尽头。
- 朱笔画封锁线、禁区，挡住敌方推进。线有承受度，压力过了临界值就被冲破；你在自己的线上划一刀，就是解封。
- 墨笔在队伍上写号令：集结、冲锋、固守、撤退。
- 队伍要带粮（参考图里的「队伍 12 · 粮 3」），后方有辎重；粮一断，士气就垮。
- 打仗由模拟自动结算，你决定路线、阵地和时机。
- 兵种随时代换：石矛 → 戈与剑 → 骑兵、弩 → 火炮、城堡 → 步枪、铁路运兵 → 战壕、飞艇 → 飞机。缴获别族的兵器，能学到新样式。

## 九、八个时代

每一代都按同一张清单来填，保证内容量：

- 6–8 个新符、8–12 张新图纸、约 20 项科技，分属生产、建造、交通、军事、社会、仪式（参考图的分类）
- 3–5 种新职业或兵种、2–3 种新资源
- 4–6 条事件链、1–2 个对手、2–3 个天才
- 一项分好几段的时代工程，一场时代考验
- 一块新地图、几个新神迹
- 一支新笔：这一代新造的东西用这一代的笔来画（炭笔、毛笔、刻刀、雕版、钢笔、绘图笔……），旧东西保持旧笔迹。纸面上的笔迹，就是这个文明的历史。

过了考验，由你决定何时升代；不升也能一直玩下去。

### 第一代 · 部落时代（石器）

- **核心问题**：活下去，聚成一族。约第 1–6 年，首玩 3–4 小时。
- **你管什么**：每一个人，十几到三十人。
- **新符**：十个象形符：日、月、雨、火、水、山、树、剑、旗、光。
  - 画在什么上面，就是什么号令：树林上的剑是砍伐，兽身上的剑是狩猎，石堆上的剑是采石，族人身上的旗是集结，河上的山是筑堤……
  - 画在天上是神迹：降雨、放晴、入夜、雷火。画在族人身上的光是降下圣光。
  - 迁徙不是符：用铅笔从营地画一条路线，再点确认。
- **新图纸**：窝棚、火塘、晾肉架、石器台、篱笆、陷阱、小路、祭坛。
- **科技**：辨识野食、打制石器、编筐、保火、熏肉、兽皮衣、围猎、渔叉、陷阱、草药、骨针、长屋、木筏、壁画、葬礼、舞祭、驯犬、观星。
- **人与天才**：首领、猎手、火守、草药师；天才如「会保火的人」「会画壁画的人」。
- **威胁**：虎、狼群、蝗虫群、寒冬、山洪、疫病、有人走失。
- **对手**：邻近的游群，会来抢火种，也可以结亲。
- **时代工程**：大祭坛与墨池。分三段，每段画一部分图纸；建成后墨的上限翻倍。
- **时代考验**：迁徙。旧营地被洪水冲毁，你要画出路线，带全族穿过兽群，走到新的河谷。

### 第二代 · 农耕时代（陶）

- **核心问题**：定居、存粮、熬过灾年。约第 6–14 年。
- **你管什么**：一个村，三五十人，以户为单位。
- **新符**：开垦、播种、收割、储粮、驱虫；神迹：不季之穗、止雨。
- **新图纸**：田（画田界）、渠（引水）、桥（筑桥）、公共粮仓、陶窑、畜栏、井、堤、村道。
- **科技**：开垦、播种、制陶、引水、筑桥、公共粮仓、驯养、织布、历法、轮作、酿酒、石磨、木构房、结绳记事、村规、渔网、独木舟、草药园。
- **新系统**：户与继承；师徒传习；季节祭；粮食会坏，陶罐能存。
- **人与天才**：陶匠、治水的人、懂历法的人。
- **威胁**：旱、涝、虫害、鼠患、游牧劫掠、地力耗尽。
- **对手**：河对岸的村子：跟它换陶器，还是跟它争水。
- **时代工程**：大渠。一条贯穿河谷的灌溉渠，分段画，每段都要绕开地形。
- **时代考验**：大水。画堤只挡得住一时，迟早要溃；画渠分洪，才过得去。
- **神格**：立教、司祭。有了司祭，族人能认得的神符多起来。

### 第三代 · 青铜时代（城邦）

- **核心问题**：权力、文字与战争。约第 14–24 年。
- **你管什么**：一座城和四周的村，一两百人。
- **新符**：征召、巡逻、守城、贸易、祭祀。
- **新图纸**：城墙（画城郭线）、宫室、工坊、铸铜炉、市集、宗庙、车道、大钟。
- **科技**：冶铜、合金、车与轮、文字、立法、税赋、度量衡、礼乐、戈与剑、战车、驿传、天文、占卜。
- **新系统**：
  - **文字**：技艺写进书简，人死了也不会失传。你写过的符，被族人抄成经文。
  - **会意（可选）**：把两个已知的符写进同一个符圈，族人就造出一个新字，比如人加木是「休」。每个新字是一项小科技。
  - **立法**：把一道神谕写成律令。
  - **阶层与税**。
- **人与天才**：铸匠、史官、将领。
- **威胁**：邻邦来犯、城中叛乱、城里的瘟疫、旱灾。
- **对手**：两三个城邦。它们供着别的神，纸上会出现另一种颜色的墨迹，跟你争信徒。
- **时代工程**：铸钟。你画出钟的剖面，钟形决定音高和钟声传多远；钟声所及之处都是你的信众。钟声由 WebAudio 按剖面现场合成。
- **时代考验**：几个城邦结盟来伐。

### 第四代 · 铁器时代（王朝）

- **核心问题**：疆域与治理。约第 24–40 年。
- **你管什么**：几座城，以及城与城之间的路，数百人。
- **新符**：屯田、征兵、宣谕、赈灾、迁民。
- **新图纸**：边墙（一条长线）、驿站、官道、运河、铁炉、粮仓、关隘、书院。
- **科技**：冶铁、铁犁、铁剑、唐刀、马镫与骑兵、弩、运河、官制、户籍、货币、丝、瓷、造纸。
- **新系统**：每座城有一位城守，从天才里任命，替你管日常；粮要沿着路运；边疆。
- **威胁**：草原骑兵、内乱、饥荒、运河决口。
- **时代工程**：长墙。在纸上画一条横贯北方的墙，族人一段段修上好几年。沿山脊画省料、好守；穿平原画修得快、难守。
- **时代考验**：大饥荒，或北方骑兵大举南下。

### 第五代 · 印刷时代（纸）

- **核心问题**：知识怎么传开。约第 40–58 年。
- **你管什么**：一国的书、学堂和军队。
- **新符**：传书、开科、远征、炮击；朱笔多一个隔离圈。
- **新图纸**：造纸坊、印坊、学堂、藏书楼、城堡、炮台、港口、船坞。
- **科技**：雕版、制版、机械印刷、火药、火炮、指南针、远洋船、医学、复式记账、学校、望远镜。
- **新系统**：一本书带着一项技艺，印多少本，就传到多少座城；学堂和开科多出天才；远征队有人数、辎重和粮。
- **人与天才**：印工、医者、炮匠、航海家；东边的部落有一个会「制版」的天才。
- **威胁**：瘟疫（日志里一串名字接连病倒）、寒潮、异端（印刷也让别的教义传开）。
- **对手**：东边的部落。打败他们，带回他们的天才。
- **时代工程**：付印《神之手册》。把你的手册印出来发遍诸城，信仰大涨，也会引来异端的反驳。
- **时代考验**：瘟疫之年。靠医学、用朱笔画隔离区、降下圣光，三条路各有代价。

### 第六代 · 蒸汽时代（机械）

- **核心问题**：机器与劳动。约第 58–72 年。
- **你管什么**：工厂、铁路和城市。
- **新符**：开工、停工、调度、救灾。
- **新图纸**：水车（水力机械）、蒸汽机、工厂、煤矿、铁路（画轨道）、车站、钢厂、码头。
- **科技**：水力机械、蒸汽动力、铁路货运、钢、纺织机、机床、化肥、罐头、银行、报纸。
- **新系统**：
  - **物流**：铁路把原料运进工厂。
  - **工人和工时**。
  - **污染**：烟灰弄脏纸面，健康和爱戴随之下降。
  - **城市化**：人往城里搬。
  - **信仰下滑**：信仰从这一代开始自然下滑。
- **人与天才**：工程师、机械师、实业家。
- **威胁**：矿难、罢工、锅炉爆炸、经济危机。
- **时代工程**：横贯铁路，把东西贯通。过山要打隧道，过江要架桥，每一处难点都是一张图纸。
- **时代考验**：大罢工，或经济崩溃。

### 第七代 · 电力时代（电气）

- **核心问题**：网络与大战。约第 72–86 年。
- **你管什么**：电网、通讯和前线。
- **新符**：冲锋、固守、撤退、送电、断电。
- **新图纸**：发电站、电网（画电线）、路灯、电报和电话线、城区、战壕、铁丝网、炮兵阵地、飞艇库。
- **科技**：发电、配电与电灯、有线通信、精密制造、化工、内燃机、汽车、飞艇。
- **新系统**：
  - **夜间照明**：夜里也能干活，族人不再怕夜。
  - **有线通信**：号令即时传到通了线的城；没通线的城，要等信使把号令送到。
  - **阵地战**：见第八节。
- **威胁**：大战、大萧条、大停电。
- **时代工程**：点亮全图。电网通到每一座城，纸上的夜第一次被点亮。
- **时代考验**：大战。

### 第八代 · 航空时代（飞行）

- **核心问题**：天空，以及纸的外面。约第 86–100 年。
- **你管什么**：整张纸。
- **新符**：起飞、侦察、空投。
- **新图纸**：机库与双线跑道（六木八石四滴墨）、雷达站、计算中心、发射台（箭塔、勤务塔、发射控制）。
- **科技**：航空工程（解锁侦察机，探索范围 +50%，空中补给）、计算、火箭推进、火箭工程、卫星。
- **人与天才**：像林溪这样的工程天才，能把箭塔、勤务塔和发射控制画进同一套图纸。
- **时代工程**：发射。

## 十、结局

我的建议：火箭冲出纸面。族人第一次看见纸的边缘、桌面，和握着笔的你。

- **爱戴高**：火箭里装着一封信，是用你教他们的符写成的。
- **敬畏高**：火箭是冲你来的。他们要划破纸面，摆脱你。
- **信仰低**：他们已经不需要你。火箭飞向别处，你在纸上落下最后一笔。

**崩溃不等于结束。** 族人死光或城邦覆灭之后，过几十年，会有新的一族在废墟上醒来，从壁画和残书里找回一部分技艺。这算一段黑暗年代。

## 十一、怎么做

| 部分 | 做法 |
|---|---|
| 平台 | 电脑优先（鼠标、数位板），也支持平板加触控笔。网页还是 Godot，见第十四节 |
| 世界 | 3/4 俯视的纸面地图，白纸迷雾。地图分块缓存，只重画变了的部分 |
| 族人 | 每人一套需求和手艺，按打分挑活，规模到几百人。后期按户、按城聚合模拟，远处的人不逐个算 |
| 识别 | 见第四节。推理代码手写，CNN 只有几十 KB，不引第三方库 |
| 画风 | 水彩纸面加墨线；每代一支新笔的渲染器；污染、战火、爱戴、敬畏各有一层纸面痕迹 |
| 声音 | WebAudio 合成：从骨笛、陶埙、编钟、古琴，到工厂和电报的声音 |
| 工具 | 已有：符号实验室；合成样本（`src/recog/synth.js`）；`tools/train`（训练）；`tools/tune`（调门槛）；`tools/glyphcheck`（识别体检、混淆表、真人样本评测）。以后加：`tools/sim`（机器人按脚本玩，调粮、人口、墨、信仰）；`tools/shots`（按真实时钟截图） |

## 十二、开发顺序

先把第一代做满，它本身就是一部完整的「部落篇」。之后每一代出一个大版本。

| 里程碑 | 内容 | 过关线 |
|---|---|---|
| M0 识别样机（已做，见 [M0 报告](M0_报告.md)） | 符号实验室；第一代 10 个符的合成数据、模型和混淆表；三支笔的输入分流；两张图纸的拟合 | 真人样本第一猜就对 ≥97%，乱画被拒 ≥95%。机器测（合成样本，各语境平均）：常态 99.9%，潦草 96.7%；见过的乱画拒 99.4%，没见过的 85.0% |
| M1 部落白盒（已做，见 [M1 报告](M1_报告.md)） | 白纸地图；族人模拟（需求、活计、季节）；6 个号令符、4 张图纸、2 个神迹；墨与信仰；有名字的族人；日志 | 机器人能活过两年。机器测：机器人当神，20 个种子全部活过两年且剩 ≥ 8 人（平均 11.8 人）；没有神只有 6 个（平均 4.3 人，7 个灭族） |
| M2 部落做满 | 第一代全部科技、威胁、对手、天才、时代工程和考验 | 首玩 3–4 小时；机器人模拟里粮、人口、墨的曲线合理 |
| M3 起 | 每一代一个大版本 | 同 M2 |

能用机器测的先测；真人试玩作复核点，不卡开发。

## 十三、风险

| 风险 | 对策 |
|---|---|
| 符号认错 | 三支笔分流；按画在什么上缩小候选；CNN、点云、原型三路合判；学玩家的笔迹；虚影、撤回、确认三道关；实在不行就退回盖印和点选 |
| 符号太多记不住 | 符号尽量象形；手册里能描红练习；熟练的活变成常令；同场只用十来个 |
| 内容量太大（八代，每代 3–5 小时） | 一代一个大版本，先做满第一代；用系统生成内容（人的生老病死、事件链、对手），不全靠手写 |
| 后期操作爆炸 | 每一代管的东西往上升一层；城守代管；常令自动化 |
| 一代太长、发闷 | 每代分三幕：开局有新东西，中段有危机，末段是工程和考验；随时快进；过了考验自选何时升代 |
| 工业化以后神没事干 | 把信仰下滑做成刻意的转折，神的玩法从下令变成托梦、显灵、立法 |
| 数值难平 | 照现有项目的做法，先让机器人模拟跑 |

## 十四、要你拍板的

1. **输入**：三支笔（推荐）；全自由画；或者不写符，只画线和图纸。
2. **平台**：网页（推荐：零依赖，平板加笔画起来最顺，也接得上现有的发布流程）；或 Godot（参考图里的 `glyph_cnn.tres` 是 Godot 资源，逆弹也是 Godot）。
3. **结局**：火箭冲出纸面见到神（推荐）；或者普通的太空终局。
